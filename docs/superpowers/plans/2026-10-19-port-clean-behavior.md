# Перенос clean-mvp в main домен за доменом

## Зачем

На стенде main (snmpsh.ru, `sha-b466e26`) при подготовке демо всплывает:

- ни у одного из 301 кадра нет камеры: при загрузке камеру не выбрать;
- дата ни у одного кадра не со штампа, только из имени файла или вручную; имя файла у
  выгрузок с камер — момент выгрузки, а не съёмки (49 кадров Березников «за 27.09»);
- камера со стримом ни разу не попробовала снять кадр (`STREAM__ENABLED=false`);
- итог «Отклонений нет» рядом с четырьмя критичными отклонениями (Березники);
- три критичных отклонения из одного снимка за день, под которым сам стенд пишет
  «по одному кадру вывод делать нельзя» (Москва, Пермь);
- этап одновременно «опережает на 57 дней» и с критичным отклонением;
- 45 строк графика Березников — 45 этапов, название этапа — абзац перечня работ.

Под капотом расхождение шире кода детектора. Детектор одинаковый (те же веса
`mocs_m_best@e7b71474`, imgsz 960, conf 0.25), эталоны штампа побайтно те же. Разное — всё,
что после рамок: в clean время кадра с часами, светлое время суток, проверка серии
штампов камеры, наблюдаемость по доле камер, неподвижная техника, работа и простой по
парам кадров, зона камеры, этапы из работ графика, решения по гипотезам. Поэтому
переносим домены clean целиком, а не адаптерами к схеме main.

## Правила

1. Домен main заменяется реализацией clean вместе с его экранами. Код clean берётся из
   `../LCT-7-clean` (ветка `feat/clean-project`) и правится под то, что остаётся от main.
2. Остаётся от main: вход и регистрация (`user`, JWT), лимит запросов, деплой (Traefik,
   `deploy/`), лендинг, подключение роутеров и провайдеров в `plugins/` — к нему же
   встаёт `feat/notifications`.
3. Миграции продолжают цепочку main (`0013+`): переводят таблицы main в схему clean и
   переносят данные (стройки, графики, камеры, снимки). Производное (наблюдения,
   статусы, отклонения) пересчитывается.
4. Каждый PR — в `port/clean`, с зелёными `make check`, тестами бэкенда,
   `make front-check`, тестами ML по затронутому. Между PR 2 и PR 4 ветка не
   деплоится: оценка выключена, пока не перенесён движок.
5. В `main` — один PR из `port/clean` после прогона `docs/demo.md` на стенде.
