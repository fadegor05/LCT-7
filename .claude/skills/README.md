# Superpowers skills

These project-level Claude Code skills are imported verbatim from
[obra/superpowers](https://github.com/obra/superpowers) (commit `7c9a06c`-era `main`,
imported 2026-09-20), distributed under the MIT License (Copyright (c) 2025 Jesse Vincent).
See `LICENSE-superpowers.txt` in this directory for the full license text.

They provide a composable software-development methodology (brainstorming,
writing/executing plans, TDD, systematic debugging, subagent-driven development,
code review, git worktrees, etc.) for Claude Code sessions working in this repo.

To pick up updates, re-sync the `skills/` directory from the upstream repo and
review the diff before committing.
