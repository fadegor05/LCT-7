# Эталонная разметка дат съёмки

`date_stamps_groundtruth.csv` — проверенные глазами даты для всех 100 снимков из
`7.ДГП_датасеты/Строительная_техника`. Файл ведётся вручную и служит опорой для
замера качества `tools/read_date_stamp.py`: без него нельзя сказать, стало ли
лучше после правки порогов, гипотез предобработки или смены OCR-движка.

## Колонки

| Колонка | Значение |
|---|---|
| `image` | имя файла снимка |
| `expected_date` | верная дата в ISO; пусто, если штампа нет |
| `has_stamp` | `yes` / `no` — присутствует ли штамп на кадре физически |
| `source` | как получено значение, см. ниже |
| `note` | почему автоматика ошиблась, если ошиблась |

Значения `source`:

- `ocr_verified` — распознано автоматикой и сверено с исходным вырезом кадра;
- `manual_read` — автоматика ошиблась или пропустила, дата прочитана глазами
  на полном разрешении;
- `visual_check` — штамп на кадре отсутствует, проверено просмотром.

## Как получено

Контактные листы вырезов правого нижнего угла всех 100 снимков, три прохода:

1. 48 распознанных сверены с исходными вырезами — 47 совпали, один расходится;
2. 52 нераспознанных просмотрены в увеличении — на четырёх штамп нашёлся;
3. оставшиеся 48 «без штампа» перепроверены в полном разрешении, штампов нет.

Знаменатель важен: 48 кадров не имеют штампа вообще, и включать их в recall
распознавания некорректно. Считать нужно от 52.

## Текущее состояние

| | |
|---|---|
| Снимков со штампом | 52 из 100 |
| Распознано автоматикой | 48 — recall 92 % от 52 |
| Из них верно | 47 — точность 98 % |

Расхождения, зафиксированные в эталоне:

| Снимок | Верная дата | Что не так |
|---|---|---|
| #47, #48 | 25.06.2024 | пропуск: бледный красный штамп на грунте того же тона |
| #63 | 24.10.2024 | пропуск: оранжевый штамп на оранжевом грунте |
| #88 | 21.01.2024 | пропуск: штамп распался на фрагменты |
| #89 | 21.01.2024 | ошибка: прочитано `21:01.2022`, спутана последняя цифра |

Случай #89 стоит помнить при доработке: две независимые гипотезы предобработки
согласились на неверном ответе, потому что идут через одну модель. Согласие
гипотез — слабый сигнал доверия, а не проверка. Надёжнее ловится тем, что дата
выпадает из помесячной серии: соседний кадр #89/#90 датирован 21.01.2024.
