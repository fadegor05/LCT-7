# API

Бэкенд отдаёт 37 эндпоинтов под префиксом `/api` (настройка `API_PREFIX`). Интерактивная документация OpenAPI открывается на `/api/docs`, схема на `/api/openapi.json`.

## Аутентификация

Все эндпоинты кроме `/auth/login`, `/auth/register`, `/health`, `/ready` и `/version` требуют заголовка `Authorization: Bearer <jwt>`. Без авторизации вернёт `401 Требуется авторизация`.

### POST /api/auth/login

Вход по логину и паролю.

**Тело запроса:**
```json
{
  "login": "string",
  "password": "string"
}
```

**Ответ 200:**
```json
{
  "access_token": "eyJhbGc...",
  "token_type": "bearer",
  "user": {
    "id": "uuid",
    "full_name": "string",
    "login": "string",
    "created_at": "datetime"
  }
}
```

**Ошибки:**
- `401 Неверный логин или пароль` — логин не найден или пароль неверен. Одно и то же сообщение для обеих случаев.
- `429 rate_limited` (код ошибки) — слишком много попыток входа по логину. Лимит задаётся `AUTH__LOGIN_RATE_LIMIT_PER_MIN` (по умолчанию 10 попыток в минуту). Подождите и повторите.

JWT подписан алгоритмом HS256, содержит claims `sub` (user_id), `iat` (время создания), `exp` (время истечения). Время жизни токена — `AUTH__TOKEN_TTL_MINUTES` (по умолчанию 720 минут). Токены не обновляются, новый токен нужно получить повторным входом.

### POST /api/auth/register

Саморегистрация: создаёт пользователя и сразу выдаёт токен, как вход.

**Тело запроса:**
```json
{
  "login": "string",
  "password": "string",
  "full_name": "string"
}
```

`login` от 3 до 64 символов, приводится к нижнему регистру, пробелы по краям срезаются. `password` от 8 до 256 символов. `full_name` необязателен, по умолчанию равен логину.

**Ответ 201:** тот же, что у `/auth/login` (`access_token`, `token_type`, `user`).

**Ошибки:**
- `409 Логин уже занят` (код `login_taken`).
- `422` — логин или пароль не прошли проверку длины.
- `429 rate_limited` — слишком много регистраций. Лимит `AUTH__REGISTER_RATE_LIMIT_PER_MIN` (по умолчанию 5 в минуту) считается по адресу клиента. За Traefik это адрес прокси, поэтому лимит общий для всех.

Все зарегистрированные пользователи равны: ролей нет, каждый видит только свои стройки.
